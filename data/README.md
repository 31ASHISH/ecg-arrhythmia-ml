# data/README.md

## Data Directory

### data/raw/
MIT-BIH Arrhythmia Database records downloaded from PhysioNet.
Each record consists of three files:
- `{record_id}.hea` — header file (metadata)
- `{record_id}.dat` — binary signal data
- `{record_id}.atr` — expert beat annotations

**Download**: `python scripts/download_data.py [--mode fast|full]`

**Source**: https://physionet.org/content/mitdb/1.0.0/

**Citation**: Moody GB, Mark RG (2001). The impact of the MIT-BIH Arrhythmia Database.
IEEE Engineering in Medicine and Biology Magazine, 20(3):45-50.

### data/processed/
Preprocessed outputs generated by the pipeline:

| File | Contents |
|------|----------|
| `segments.parquet` | Heartbeat windows + metadata (~110k rows) |
| `features.parquet` | 66-feature engineered matrix |
| `meta.parquet` | Labels + record IDs aligned with features |
| `waveforms.parquet` | Raw flattened waveform matrix (200 values each) |

**These files are NOT committed to git** (see .gitignore).
Run `python scripts/preprocess.py` and `python scripts/build_features.py` to regenerate.
